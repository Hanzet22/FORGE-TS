# Privacy and Safety Scope
- Request only Android permissions needed for an enabled feature.
- Do not upload diagnostic output by default.
- Do not store passwords, SSH private keys or authentication tokens in plain text.
- Never embed Supabase service-role credentials or provider secrets in the APK.
- Host Checker is for authorized hosts, not mass scanning or exploitation.
- OS command content is educational reference material, not unrestricted command execution.
- Explain when a network feature may disclose the device public IP to a remote service.
